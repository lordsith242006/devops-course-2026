# IDE vs CLI: заметки по Git

## Удобно в VS Code

1. **Визуальный diff** — сразу видно добавленные/удалённые строки, не нужно читать `git diff` в терминале.
2. **Встроенный merge-редактор** — конфликты решаются кнопками «Accept Current/Incoming», без ручной правки маркеров.
3. **GitLens (git blame наглядно)** — у каждой строки видно автора и дату изменения, в терминале это делать неудобно.
